Full stack Java project: **Spring Boot REST API + JWT security + MySQL**, with a vanilla HTML/CSS/JS frontend served by the same application.

## Tech stack
Java 17 · Spring Boot 3.2 · Spring Data JPA / Hibernate · MySQL · Spring Security + JWT (jjwt) · REST APIs · Bean Validation · Spring Mail · Maven · Postman

## Run it
1. Install JDK 17+, Maven and MySQL 8.
2. Set your DB credentials (defaults: `root` / `root`; the `job_portal` database is created automatically):
   ```
   export DB_USERNAME=root
   export DB_PASSWORD=yourpassword
   ```
3. Start the app:
   ```
   mvn spring-boot:run
   ```
4. Open http://localhost:8080

An administrator account is initialized automatically on first application startup using the configured environment variables.

## Modules
| Role | Features |
|---|---|
| Job Seeker | Register/login, profile, resume upload (PDF/DOC/DOCX), search + filter + sort + paginate jobs, apply with cover letter, track status, skill-based recommendations |
| Recruiter | Register with company, post / update / delete jobs, view applicants, shortlist / reject, download resumes |
| Admin | Dashboard stats, enable/disable/delete users, remove jobs, monitor all applications |

Cross-cutting: JWT auth, role-based authorization (`@PreAuthorize`), pagination & sorting, email notifications (async, logged unless enabled), global exception handling, transactions in the service layer.

## Database design
- `users` (1) ── (N) `jobs` — recruiter posts many jobs
- `users` (1) ── (1) `job_seeker_profiles`
- `jobs` (1) ── (N) `applications` (N) ── (1) `users` — unique (job, applicant) prevents double applying

Tables are generated by Hibernate (`ddl-auto=update`).

## REST API (test with Postman)
Send `Authorization: Bearer <token>` on protected calls (token comes from login/register).

| Method | Endpoint | Role |
|---|---|---|
| POST | `/api/auth/register` `{fullName,email,password,role,companyName?}` | public |
| POST | `/api/auth/login` `{email,password}` | public |
| GET | `/api/jobs?keyword=&location=&jobType=&maxExperience=&page=&size=&sortBy=&dir=` | public |
| GET | `/api/jobs/{id}` | public |
| GET | `/api/jobs/recommendations` | JOB_SEEKER |
| GET/PUT | `/api/profile` | JOB_SEEKER |
| POST | `/api/profile/resume` (form-data `file`) | JOB_SEEKER |
| POST | `/api/applications/jobs/{jobId}` `{coverLetter?}` | JOB_SEEKER |
| GET | `/api/applications/my` | JOB_SEEKER |
| POST | `/api/jobs` | RECRUITER |
| PUT/DELETE | `/api/jobs/{id}` | RECRUITER (owner) |
| GET | `/api/jobs/my` | RECRUITER |
| GET | `/api/jobs/{id}/applicants` | RECRUITER (owner) |
| PATCH | `/api/applications/{id}/status` `{status: SHORTLISTED｜REJECTED}` | RECRUITER (owner) |
| GET | `/api/applications/{id}/resume` | RECRUITER (owner) / ADMIN |
| GET | `/api/admin/stats`, `/users`, `/jobs`, `/applications` | ADMIN |
| PATCH | `/api/admin/users/{id}/enabled?value=true｜false` | ADMIN |
| DELETE | `/api/admin/users/{id}`, `/api/admin/jobs/{id}` | ADMIN |

Sample job body:
```json
{ "title": "Java Backend Developer", "description": "Build REST APIs", "location": "Bengaluru",
  "jobType": "FULL_TIME", "skillsRequired": "java, spring boot, mysql", "experienceRequired": 1,
  "salaryMin": 600000, "salaryMax": 1200000 }
```

## Enable real emails
Set `app.mail.enabled=true` and the `spring.mail.*` SMTP settings in `application.properties` (example for Gmail is included, commented).

## Project structure
```
src/main/java/com/jobportal
├── config/       DataInitializer (seeds admin)
├── controller/   Auth, Profile, Job, Application, Admin
├── dto/          Dtos (request/response records)
├── entity/       User, JobSeekerProfile, Job, Application + enums
├── exception/    custom exceptions + GlobalExceptionHandler
├── repository/   Spring Data JPA repositories
├── security/     JwtUtil, JwtAuthFilter, SecurityConfig
└── service/      business logic, email, file storage
src/main/resources/static   frontend (index.html, css/, js/)
```
